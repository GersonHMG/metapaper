# Experiment B3: Long temporal context, continuous EEG

Frozen grouped spatial encoder (per-second classifier, its own output = **none**, no context). **avg** rows: non-learned moving average of the `none` probabilities over the same window (control). TCN rows: `TemporalHead` TCN over the per-second embeddings with receptive field 13/29/61/125 s, causal (past only) and non-causal (both sides). Evaluated on whole test recordings, seizure-free ones included: 24 patients, 952 test hours. Threshold per model and fold = best per-second F1 on validation seconds. See `experiments/experiment_b3_long_context.md`.

Events: positive seconds, gaps < 10 s merged. A seizure is detected if an event overlaps it; latency = first detected second − onset; an event overlapping no seizure is a false alarm. Boundary seconds: within ±2 s of an onset or offset. Per-fold rows: `b3_long_context_folds.csv`.
